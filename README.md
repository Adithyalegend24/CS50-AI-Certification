[![Python](https://img.shields.io/badge/Python-3.x-yellow)](https://www.python.org/)

This repository contains my solutions and implementations for **CS50's Introduction to Artificial Intelligence with Python**, a course that explores fundamental concepts and practical applications of Artificial Intelligence using Python.

The projects cover **search, knowledge representation, probability, optimization, machine learning, neural networks, and natural language processing**.

---

| Module           | Topics                           |
| ---------------- | -------------------------------- |
| Search           | BFS, DFS, A* Search              |
| Knowledge        | Propositional Logic, Inference   |
| Uncertainty      | Probability, Bayesian Networks   |
| Optimization     | Constraint Satisfaction, Minimax |
| Machine Learning | Classification, Regression       |
| Neural Networks  | Image Classification             |
| NLP              | Parsing, Attention               |
